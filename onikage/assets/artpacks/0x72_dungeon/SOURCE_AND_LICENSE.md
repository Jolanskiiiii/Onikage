# 0x72 Dungeon Tileset source and license

- Creator: 0x72 (Robert)
- Pack: 16x16 Dungeon Tileset v5
- Official source: https://0x72.itch.io/16x16-dungeon-tileset
- License: the official listing states CC0 1.0; the downloaded archive contained no license file.
- Preview files: selected original atlas, JSON atlas metadata, and standalone tile PNGs. No recoloring or gameplay use is applied.

The atlas metadata describes a single 512x256 Aseprite frame. Standalone images have mixed native dimensions; use the JSON metadata or named image dimensions rather than assuming a uniform atlas grid.
